## Milestone rules

A milestone is complete only when:

1. Its implementation exists.
2. It matches the approved Figma scope.
3. Manual verification is documented.
4. Requested automated checks pass.
5. Documentation is synchronized.
6. The user confirms completion.

Only one milestone or subtask should be active at a time.
