# Showtime and pricing static designs

Mockup tĩnh cho các trang bị ảnh hưởng bởi mô hình giá mới. Repository BE/FE không bị chỉnh sửa.

## Trang trong bộ thiết kế

- **admin-showtime-create.html**: tạo suất chiếu, xem layout PUBLISHED và preview giá theo khung giờ/nhóm vé.
- **admin-pricing-policy.html**: cấu hình giá cơ bản, ưu đãi và phụ thu theo từng rạp.
- **customer-ticket-selection.html**: chọn ghế, gán TicketCategory cho từng ghế và xem báo giá.
- **styles.css**: token màu, kích thước, spacing và layout dùng chung.

Mở file HTML cùng thư mục với styles.css. Bảng giá hiển thị là dữ liệu mẫu theo ảnh tham khảo, chưa phải cấu hình production. Cần xác nhận ưu tiên ưu đãi và đơn vị/cộng dồn phụ thu trước khi tích hợp.
